# Nimbus
A weather app built with plain HTML, CSS and JavaScript using the Open-Meteo API.

**Live demo:** https://nimbus-snowy-one.vercel.app/

## Known issues
- Day/night is not detected: cities where it is night still show the sun theme.
- Needs more testing on mobile.

## Planned fixes
- Add night mode using the API's `is_day` value.
